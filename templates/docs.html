Getting Started

Welcome to the AI Humanizer API documentation. Our API allows you to transform AI-generated text into natural, human-like content programmatically. This powerful tool can be integrated into your applications, workflows, and platforms.

Pro Tip: Get your API key from the Dashboard to start making requests immediately.

Authentication

All API requests require authentication using an API key. Include your API key in the request headers.

API Key Header

Header 
X-API-Key: hmnz_your_api_key_here
Security: Never share your API key publicly or commit it to version control. Keep it secure like a password.

API Endpoints

POST /humanize

Transform AI-generated text into human-like content.

Endpoint 
POST https://your-domain.com/humanize

Request Format

Headers

Header Value Required
Content-Type application/json Required
X-API-Key Your API key Required

Request Body Parameters

Parameter Type Description Required
text string The AI-generated text to humanize Required
tone string Output tone: "standard", "professional", "casual", "academic" Optional
deep_mode boolean Enable advanced humanization (Chaos Mode) Optional

Example Request

JSON 
{
  "text": "The quick brown fox jumps over the lazy dog.",
  "tone": "professional",
  "deep_mode": true
}

Response Format

Success Response (200 OK)

JSON 
{
  "original": "The quick brown fox jumps over the lazy dog.",
  "humanized": "A nimble auburn fox leaps across the sluggish canine.",
  "ai_probability": "0.8%",
  "confidence": "99.7%",
  "classification": "Human-Written",
  "diff_html": "<span class='changed'>...</span>",
  "longest_unchanged": "the",
  "structural_changes": "87.3%",
  "changed_words": 8
}

Response Fields

Field Type Description
original string The original input text
humanized string The humanized output text
ai_probability string Predicted AI detection probability
confidence string Human classification confidence score
classification string Final classification result
structural_changes string Percentage of structural modifications
changed_words integer Number of words modified

Error Handling

Error Responses

400 Bad Request 
{
  "error": "No text provided"
}
401 Unauthorized 
{
  "error": "Invalid or inactive API key"
}
500 Internal Server Error 
{
  "error": "Processing failed. Text may be too long."
}

HTTP Status Codes

Code Meaning Description
200 OK Request successful
400 Bad Request Invalid request parameters
401 Unauthorized Invalid or missing API key
500 Server Error Internal processing error

Rate Limits

API requests are monitored to ensure fair usage. Current limits:

  • No hard rate limit currently enforced
  • All requests are logged for usage tracking
  • Excessive usage may result in temporary throttling

Code Examples

Python

Python 
import requests

url = "https://your-domain.com/humanize"
headers = {
    "Content-Type": "application/json",
    "X-API-Key": "hmnz_your_api_key_here"
}
payload = {
    "text": "Your AI-generated text here",
    "tone": "professional",
    "deep_mode": True
}

response = requests.post(url, json=payload, headers=headers)
data = response.json()

print(f"Humanized: {data['humanized']}")
print(f"Confidence: {data['confidence']}")

JavaScript (Node.js)

JavaScript 
const fetch = require('node-fetch');

const url = 'https://your-domain.com/humanize';
const options = {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-API-Key': 'hmnz_your_api_key_here'
  },
  body: JSON.stringify({
    text: 'Your AI-generated text here',
    tone: 'professional',
    deep_mode: true
  })
};

fetch(url, options)
  .then(res => res.json())
  .then(data => {
    console.log('Humanized:', data.humanized);
    console.log('Confidence:', data.confidence);
  })
  .catch(err => console.error(err));

PHP

PHP 
<?php
$url = 'https://your-domain.com/humanize';
$data = array(
    'text' => 'Your AI-generated text here',
    'tone' => 'professional',
    'deep_mode' => true
);

$options = array(
    'http' => array(
        'header'  => "Content-type: application/json\r\n" .
                     "X-API-Key: hmnz_your_api_key_here\r\n",
        'method'  => 'POST',
        'content' => json_encode($data)
    )
);

$context  = stream_context_create($options);
$result = file_get_contents($url, false, $context);
$response = json_decode($result);

echo "Humanized: " . $response->humanized . "\n";
echo "Confidence: " . $response->confidence . "\n";
?>
